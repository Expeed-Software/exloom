# exloom — Claude Code plugin

A team-oriented development workflow for Claude Code: a disciplined loop (brainstorm → plan → execute → prove → review), an auditable handoff between developers, and an opt-in, hooks-enforced review gate.

## Install

```
/plugin marketplace add https://github.com/Expeed-Software/exloom
/plugin install exloom@exloom
```

**Full documentation** — what's inside, how the loop works, and how to turn on the enforcement gate — lives in the [repository README](../../README.md).
